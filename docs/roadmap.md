## 1. FX の重ねがけと並列

### 決めたこと

**重ねがけ**

- エフェクト 10 種それぞれに 3 つずつ、合計 30 個の「ユニット」を持つ。
  パラメーター表は固定のままなので、どのユニットのスライダーも「うごき」の行き先にできる。
- 1 つ目は今までと同じキーと ID（`dist.drive`、sid 522）。2 つ目・3 つ目は `dist2.drive`（sid 1522）、`dist3.drive`（sid 2522）。
- ボードの「使っていないエフェクト」には、種類ごとに次に使える 1 つだけを出す。
  スイッチを入れると流れの最後に加わり、同じ種類の次の 1 つが待機に現れる。
- 設定パネルの「同じものをもう 1 つ重ねる」で、いまの設定をコピーしてすぐ後ろに置ける。

**並列（分岐）**

- 流れの途中に分岐を 1 か所だけ作れる：`手前 → [道 A ‖ 道 B] → 後ろ`。
- ユニットごとに「通る道」（本線・A・B）を持つ。どれかを A か B に入れると分岐ができ、すべて本線に戻すと消える。
  分岐の場所は、並び順の中で最初に出てくる分岐ユニットの位置。ほかの分岐ユニットはそこに集まる。
  このルールなら、どんな並び順と道の組み合わせでも必ず 1 つの形に決まる。
- 分け方は 4 種類。
  - 同じ音を 2 つに（A と B に同じ音。まとめるときは半々）
  - 低音と高音（境目の高さを指定。24 dB/oct のクロスオーバー）
  - 中央と左右（Mid/Side）
  - 左と右
- 原則：**道が空のとき、分岐は音を変えない**。
  低音と高音だけは位相が回るが、音量と音色は変わらない。
- 「まぜ具合」でまとめるときの A と B の割合を変えられる。

**Serum 2 の 3 ラック方式にしなかった理由**

Serum 2 は音源ごとにバスへの送り量を決める方式で、初心者には配線の意味が伝わりにくい。
「ここで 2 つに分かれて、ここで合流する」はボード上の線の形そのままなので、こちらを選んだ。

### 共有 URL とファイル

- パッチのバイナリ形式はバージョン 1 のまま。並び順と道はセクション 6 に書く。
  1 ユニット 1 バイト（下位 6 ビットがユニット番号、上位 2 ビットが道）で、初期状態と違うところまでの前半だけを書く。
- 古い URL（セクション 5、10 個の並び順）はそのまま開ける。
- JSON プリセットは `fxOrder`（ユニット名の並び）と `fxLanes`（`{ "dist2": "a" }`）。

### Serum への書き出し

- 重ねがけは、メインのラックに同じ種類のモジュールを並べて書き出す。
- 分岐は Serum のバス配線の形式が確認できていないため、`手前 → A → B → 後ろ` の順に 1 本に並べて書き出し、変換メモで知らせる。

## 2. ウェーブテーブルの手描きと音声取り込み

### 決めたこと

**自分のテーブル**

- 音色（パッチ）ごとに「自分のテーブル」を 2 つ持てる。どちらのオシレーターからも選べる。
- 1 つのテーブルは 1〜16 コマ。1 コマは音の波 1 回ぶんで、128 個の点（1 点 1 バイト）で持つ。点と点は直線で結ぶ。
  描いた線がそのまま音になり、角のある波形（ノコギリ、矩形）も高い倍音まで出る。
- この大きさにしたのは共有 URL に入れるため。1 コマ 128 バイト、URL では約 170 文字。
  16 コマだと約 2,700 文字になるので、共有ダイアログで「長いリンクです」と知らせる。
- 内蔵テーブルの番号（`oscA.wt`）とは別に、`oscA.userTable`（Off / User 1 / User 2）で切り替える。
  内蔵テーブルは今後も後ろに足していけるよう、番号の並びを自分のテーブルと混ぜない。
- 高さは音量に関係しない（内蔵テーブルと同じく、コマごとに自動でそろえる）。

**描く画面**

- オシレーターの設定でテーブル一覧を開き、「自分のテーブル」を選ぶとそのまま描く画面が開く。
- 大きな枠の中をなぞって描く。はじめの形（サイン・三角・ノコギリ・矩形）と「なめらかにする」だけを置く。
- コマは下に並び、＋で足す（いまのコマのコピー）。コマを選ぶと「波形の位置」もそこへ動き、そのコマの音が聴ける。
- 描いている最中も音に反映する。変わったコマだけ作り直すので、1 回の更新は 0.3 ms ほど。
- 画面を開いたまま、PC のキーと「押しているあいだ鳴らす」ボタンで音を出せる。

**音声から作る**

- 音声ファイルを選ぶ（またはドロップする）と、音の中から等間隔に 1・4・8・16 か所を選び、それぞれ波 1 回ぶんをコマにする。
- その場所ごとに音の高さ（1 周期の長さ）を自己相関（YIN）で求め、数周期ぶんから倍音の強さと位相を測って 128 点に直す。
- コマどうしがなめらかにつながるよう、基音の位相をそろえる。
- 高さが見つからない音（ノイズ、ドラムなど）は、2048 サンプルごとに切り取る。そのことを画面で伝える。
- 1 周期だけのファイル（シングルサイクル波形）もそのまま読める。ずっと同じ形の音は 1 コマにまとめる。
- 解析はブラウザの中だけで行い、音声はどこにも送らない。

**やらなかったこと**

- 倍音を棒グラフで描く編集、数式での生成、マイクからの録音。必要になったら足す。
- Serum 形式のウェーブテーブル WAV（2048 サンプル × コマ）の正確な読み込み。ふつうの音声として解析するので、近い形にはなるが同じにはならない。

### Serum への書き出し

自分のテーブルも WAV にして一緒に書き出す。ほかの音色のテーブルと重ならないよう、ファイル名は中身から決める（`User 349e76ba.wav` など）。

## 3. フィルター 2 基目とオシレーター C

### 決めたこと

- **オシレーター C**：A・B と同じウェーブテーブルのオシレーター。初期状態はオフ。FM・AM・RM の変調元は A（A と B は互いに変調し合う）。変調元が先に鳴るよう、処理の順番は毎回決め直す
- **フィルター 2**：フィルター 1 と同じ 19 タイプ。初期状態はオフ。つなぎ方は「直列」（フィルター 1 の後ろ）か「並列」（横に並ぶ）
- **並列での行き先**：音源（オシレーター 3 基・サブ・ノイズ）ごとに「フィルター 1／フィルター 2／両方」。両方は半分ずつ入れて足すので、素通しのときは音量が変わらない。オフのフィルターを選んだ音源は、そのフィルターがないものとして進む
- **ボード**：直列ではフィルター 2 が流れの中でフィルター 1 の後ろに並び、並列やオフのときはフィルター 1 の下（スマホでは横）に置く。音源からの線は、選んだフィルターへ伸びる
- **保存形式**：新しいパラメーターは新しい安定 ID（オシレーター C は 800 番台、フィルター 2 は 840 番台）。古いリンクは、どちらもオフのまま開く
- **Serum への書き出し**：オシレーター C は Serum の 3 番目のオシレーターへ、フィルター 2 は 2 番目のフィルターへ。フィルター同士のつなぎ方は Serum 側の書き方が分からないので移さず、変換メモで知らせる
- **負荷**：8 音で、3 基とも鳴らしてフィルター 2 基を直列にしても実時間の約 4%（1 基とフィルター 1 基なら約 3%）

## 4. アルペジエーター

### 決めたこと

- **置き場所**：エンジンの中、鍵盤とボイスのあいだ（`engine/src/arp.rs`）。テンポに正確に合わせるため、画面側のタイマーではなく音声スレッドで刻む
- **設定**（安定 ID 860 番台、すべて全体で 1 つ。つながりの行き先にはしない）
  - 電源（初期状態はオフ）
  - 順番：上へ／下へ／上下（端の音はくり返さない）／弾いた順／ランダム（同じ音を続けない）／和音（押さえた音を全部いっしょに）
  - 1 音の長さ：LFO と同じ音符の一覧（初期値 1/16）
  - オクターブ：1〜4。上の音域まで続けて鳴らし、和音モードでは 1 音ごとにオクターブを上げる
  - 音の長さ：1 音のうち鳴らしている割合（5〜100%）。100% では次の音を先に鳴らしてから前の音を止めるので、モノ＋レガートならグライドでつながる
  - スウィング：2 音目ごとに遅らせる。最大で 3:1（付点のリズム）
- **鳴り始めと止まり方**：最初の鍵盤を押した瞬間に 1 音目を鳴らす。全部離したら、鳴っている音は音の長さどおりに終わり、次の拍から止まる。もう一度押すと最初から
- **オン／オフの切り替え**：押さえている鍵盤はいつも覚えておく。和音を押さえたままオンにすると、その和音がすぐパターンになり、オフにすると押さえている和音がそのまま鳴る
- **タイミング**：拍は 32 サンプル（48 kHz で約 0.7 ms）の区切りで鳴らす。時計は端数まで持ち越すので、長く鳴らしてもずれない
- **ラッチ**：専用の設定は作らず、鍵盤の「ホールド」をそのまま使う（押した鍵盤が押さえたままになり、アルペジエーターが鳴らし続ける）
- **画面**：ボードは音の流れの図なので、ノードは置かない。モノやグライドと同じく演奏にかかわる設定として、鍵盤の横に「アルペジオ」ボタン（オン／オフ）と ▾（設定）を置く。設定にはテンポも並べる。鳴っている音の鍵盤は枠が光る
- **「聴く」ボタン**：アルペジエーターがオンのときは、1 小節ずつ和音を押さえるフレーズに切り替える
- **Serum への書き出し**：Serum 2 にもアルペジエーターはあるが、プリセットでの書き方が確認できていないので移さず、変換メモで知らせる

## 4b. クリップシーケンサーと鍵盤まわり

### 決めたこと

**クリップシーケンサー**

- アルペジエーターと同じく、エンジンの中で鍵盤とボイスのあいだに置く（`engine/src/clip.rs`）
- 鍵盤を押さえているあいだ、クリップを頭からくり返す。高さは「最後に押した鍵盤 − 基準の音」だけずらす。鳴っている途中で別の鍵盤を押すと、頭に戻らずに高さだけ変わる（小節の中の位置を保つ）。全部離すと止まる
- 時間はティック（4 分音符 = 96）。1 拍〜8 小節、最大 256 音。初期状態のクリップは 1 小節のフレーズ（オンにしただけで鳴るように）
- クリップは 1 つだけ。Serum 2 は複数のクリップを切り替えられるが、まずは 1 つで「書く → 弾く」を分かりやすくする
- アルペジエーターとは同時に使わない。両方オンならクリップを優先する（画面では切り替えで片方だけになる）
- 保存：パッチ形式のセクション 9、JSON の `clip`。初期状態のままなら書かない
- Serum への書き出し：移さず、変換メモで知らせる

**ピアノロール（`src/pianoroll/`）**

- のちに別のアプリ（複数人で編集できる楽譜アプリなど）でも使えるよう、seosynth の他の部分を読み込まない独立したモジュールにする（テストで確認）
- データ：ノートは変わらない ID を持つ。編集はすべて操作（追加・削除・値の変更・クリップの長さ）として外に出し、外側がデータを持つ
- 操作は適用・逆操作・差分ができる。消えたノートへの変更や重複した追加は読み飛ばすので、複数人の操作を 1 つの順番に並べて配れば、同時編集が成り立つ
- ID は「サイト名.連番」。編集する人（画面）ごとにサイト名を変える
- 画面：canvas で描き、色は CSS 変数、文言は引数で渡す。マウス・指・キーボードで操作できる

**鍵盤まわり（UX の見直し）**

- アルペジオとクリップは同時に使えないので、2 つの独立したボタンではなく「鳴らし方：ふつう／アルペジオ／クリップ」の切り替え 1 つにまとめた
- 選んだ鳴らし方の設定は、ポップアップに隠さず、鍵盤の上の引き出しに開く。鍵盤を弾きながら設定やクリップを変えられる。切り替えたときに自動で開き、ボタンで閉じられる
- ピッチベンドと MOD ホイールを縦向きのホイールにして鍵盤の左に置いた（ハードウェアの鍵盤と同じ位置）
- 上の帯は「鳴らし方」「ホールドとオクターブ」「MIDI と弾き方の設定」の 3 つのまとまりに分けた。スマホでは文字を短くして 2 行に収める
- 鳴っている音の鍵盤が光るのは、アルペジオとクリップの両方

## 5. LFO・エンベロープ・マクロ・つながりの増設

### 決めたこと

- 数は Serum 2 と同じ：LFO 10、エンベロープ 4（1 つはアンプ用）、マクロ 8、つながり 64
- **古いリンクを壊さない**：パッチはつながりの「元」を番号で持つので、既存の番号（ENV 1〜3、LFO 1〜4、マクロ 1〜4 など）は変えず、新しい元は後ろ（18 番以降）に足した。エンジンでは `src::env(n)`、`src::lfo(n)`、`src::macro_(n)` で n 番目を引く
- **安定 ID**：ENV 4 は 360 番台、マクロ 5〜8 は 15〜18。LFO 5〜10 は 480 番以降がエフェクト（500〜）とぶつかるので、900 番台に置いた

- **画面**：「うごきを足す」で種類ごとに次の番号が出る。新しい LFO とエンベロープには、それぞれの色を足した
- **負荷**：8 音で、LFO 10 個とエンベロープ 3 個をすべてつないでも、実時間の 3.40% → 3.45%

## 6. ワープ 2 つ同時がけ

### 決めたこと

- **順にかける**：Serum 2 と同じく、1 つ目のワープで変形した位相を 2 つ目がさらに変形し、音量の変化（Flip、AM、RM など）は掛け合わせる。そのため Bend → Sync と Sync → Bend は別の音になる
- **パラメーター**：各オシレーターに「ワープ 2」と「ワープ 2 の量」を足した。安定 ID は各オシレーターの基準 ＋20・＋21（120・170・820 番台）。量はつながりの行き先にもなる
- **FM・AM・RM**：どちらのワープで選んでも、もう一方のオシレーターを聞く。相手が止まっていれば、そのワープだけ素通しになる（1 つのときと同じ）
- **帯域制限**：2 つの広がりを掛け合わせた分だけ、粗いミップを選ぶ（上限 16 倍）
- **画面**：「くわしい設定」で、1 つ目のワープを選ぶと「ワープ 2」が出る。波形のプレビューは 2 つともかけた形を描く
- **Serum への書き出し**：Serum 2 で保存されたプリセットから分かった `kParamWarpMenu2` / `kParamWarp2` に書く。量へのつながりは `WTOsc` の `kParamWarp2`（ID 3）
- **負荷**：8 音・ユニゾン 4・オシレーター 2 つで、Bend+ だけ 19.2% → Bend+ と Sync で 21.1%（実時間比）。1 つだけのときは変わらない
- 練習用の音色「学ぶ：ワープを 2 つ重ねる」を足した
